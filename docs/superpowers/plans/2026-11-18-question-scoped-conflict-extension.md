# 问题相关冲突判断扩展实施计划

目标：为已授权候选的冲突判断提供可替换扩展，并让经过冲突范围判断的回答必须额外通过问题相关性核验；默认仍严格拒答。

1. 用真实问答编排的失败测试覆盖：默认拒答、完整冲突对逐项检查、未知或异常拒答、证据身份冲突不放行，以及回答相关性核验失败不返回答案。
2. 增加本地扩展接口，只有确定性检测器成功列出所有冲突对且扩展对每一对明确判为无关时，才继续生成；必须保留原有逐字引用和最终权限复核，扩展缺失、异常或结果不明确均拒答。
3. 增加 Spring 配置的显式开关和默认严格实现；默认关闭，不能仅靠配置开关自动启用测试规则；使用合成扩展验证装配和完整问答链路。
4. 执行相关单元和集成回归，记录默认行为、扩展的责任和当前未具备业务验收的数据边界。
