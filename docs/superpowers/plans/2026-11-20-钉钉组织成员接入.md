# 钉钉组织与成员接入实施计划

1. 隔离钉钉来源的组织对账，保护本地管理员、其他来源成员和成员关系；以真实 PostgreSQL 测试停用、部分失败及回滚。
2. 完成钉钉组织采集和快照校验，处理部门层级、分页、跨部门重复成员及失败；未经确认完整的快照不触发移除或停用。
3. 补齐钉钉成员本地身份映射、受权用户目录与组织展示，保留现有 UUID、权限、会话撤销和本地管理入口。
4. 配置来源从进程环境或项目外密钥注入，默认关闭；提供管理端同步状态和手动入口。使用模拟接口验证，真实应用凭据与租户范围由后续联调提供。
5. 核实官方协议和真实租户授权范围；所有新增服务必须明确标注模拟测试与真实联调边界。
