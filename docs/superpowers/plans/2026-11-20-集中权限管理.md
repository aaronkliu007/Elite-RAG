# 集中权限管理实施计划

1. 为直接授权与角色授权记录独立来源；保守迁移旧 ACL，无法确认来源的记录保留为待确认。确保增加或撤销任一来源不改变其他来源，延续事务、审计与索引投影更新。
2. 为系统管理员及空间管理员提供经服务端鉴权的权限来源查询，并区分直接、角色、历史待确认和其他主体；支持按空间和按用户查看，避免把列表当成有效权限的完整推断。
3. 增加经授权、按姓名或账号分页搜索的最小人员目录接口，供空间管理员在集中入口选择用户，不暴露用户管理能力。
4. 增加多来源、历史迁移、鉴权隔离和分页测试，执行真实 PostgreSQL 集成验证及前端响应式与交互测试；保留既有数据并说明遗留限制。
