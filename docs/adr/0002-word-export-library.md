# ADR 0002：方案 Word 导出采用 Apache POI

- 状态：已采用
- 日期：2026-10-29

## 背景

方案工作台需要在内网部署的 Spring Boot 核心服务内，按已定稿的不可变版本即时生成 Word。首版没有企业统一模板，用户已选择内置中文样式；以后可能按公司替换模板。

## 决策

使用本地依赖 Apache POI `poi-ooxml` 5.5.1。渲染器只接受经过授权复核的定稿内容，以纯文本写入 DOCX 段落，不解析模型输出的 HTML、Markdown 嵌入资源或外部链接。文档正文和证据映射由导出服务组装，渲染器作为独立类，可由后续模板渲染实现替换。文件即时生成并返回，不在对象存储中另存一份。

## 后果

- 导出前必须重新核对知识空间、需求来源与章节证据的当前发布状态和 ACL；撤权后拒绝下载。
- DOCX 保留标题、版本、定稿时间、内容哈希、需求来源的文档版本与定位、章节顺序及章节证据的文档版本和节点标识。
- 首版排版是通用中文样式。企业封面、页眉页脚和复杂表格模板需在取得真实模板后单独实现，并保持当前授权边界。
