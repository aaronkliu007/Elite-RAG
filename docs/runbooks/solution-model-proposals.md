# 需求整理与大纲候选运行说明

在方案详情页保存人工修改后，可整理已有需求，也可从当前空间中选择有权访问的已发布文档提取需求候选。需求经异人确认后，可生成大纲候选。页面对比当前内容与候选，并展示分类、章节设置和来源。勾选审阅后可采纳为待确认修订，仍需异人确认；版本冲突时保留候选和当前编辑内容。

## 从文档提取需求

选择 1–10 个当前已发布、解析成功且有权查看的文档，输入关注问题并生成候选。检索限制在所选的确切文档版本内，最多选取 15 个证据片段；页面会提示未命中的文档和检索降级。长文档或未命中的内容可能没有被覆盖，模型引用合法也不等于结论正确，必须逐条人工核对。

候选中的“核对原文片段”读取快照对应版本和节点的脱敏片段，重新检查权限并校验内容摘要；文档换版、内容变化或授权撤销后不能继续查看或采纳。采纳时服务器使用已保存候选，复核所有所选文档（包括没有被引用的文档）和方案权限，再保存待确认修订；不能由客户端替换候选正文。证据快照保存定位和摘要，不保存片段正文。

请求中断后，页面可用原请求键查询或重发；模型结果不确定时不会自动重复调用。采纳响应丢失时保留原采纳键，重新查询原采纳结果，避免重复修订。无法恢复时可明确放弃当前浏览器中的跟踪记录，但这不撤销可能已经发生的模型调用或保存。

文档提取接口以 `/api/v1/solutions/{solutionId}/document-requirement-proposals` 为基础：生成使用 POST，查询使用 `/lookup`，采纳使用 `/adopt`，片段核对使用 `/evidence/{evidenceId}`。生成和查询使用 `Idempotency-Key`；采纳与片段核对使用 `Proposal-Key`，采纳另需自己的 `Idempotency-Key`。请求包含预期修订号、关注问题和所选文档版本，操作者始终取自登录态。该功能需要启用 OpenSearch；云模型依然默认关闭，启用须完成既有审批和脱敏配置。

明确失败或成功但尚未尝试采纳的候选可点击“放弃本次候选”，然后主动生成新的候选。此操作只清除当前浏览器会话中的展示和请求键，历史记录仍保存在数据库中；再次生成会发起新的模型请求。进行中、结果不确定或已尝试采纳的请求不能通过此入口重置。

## 接口

- `POST /api/v1/solutions/{solutionId}/proposals/requirements`：需求整理候选。
- `POST /api/v1/solutions/{solutionId}/proposals/outline`：大纲候选。
- `GET` 同一路径：查询原请求，提供 `expectedRevision` 查询参数。
- 两种请求都使用 `Idempotency-Key` 请求头。POST 请求体为 `{"expectedRevision": 0}`。操作者由登录态确定。

生成和查询均复核动作权限、当前需求版本、修订号、来源发布状态及 ACL。关闭 `rag.ai.enabled` 时生成返回 `503 MODEL_PROPOSAL_UNAVAILABLE`，不登记候选或外发请求。启用后沿用已审批网关、脱敏和额度配置，禁止记录密钥、完整提示词和供应商原始错误。

## 恢复规则与边界

候选调用不做 HTTP 自动重试，同键重放不重复调用模型。页面在当前浏览器会话中按登录用户、方案、动作和修订号保留请求键。请求未到达服务器时，可以用原键重发，不能换新键盲目重试。`RUNNING` 可查询；`FAILED` 表示明确失败；结果不明且租约到期后，查询原请求或后台扫描会将状态更新为 `INDETERMINATE`，由管理员核查供应商记录和费用。

## 后台超时扫描

`local` 装配默认每 30 秒扫描最多 100 条过期候选。只有 `RAG_WORKERS_ENABLED=true` 与 `RAG_SOLUTION_PROPOSAL_RECOVERY_ENABLED=true` 同时启用才运行。可用 `RAG_SOLUTION_PROPOSAL_RECOVERY_POLL_DELAY` 设置扫描间隔（ISO 8601 时长，如 `PT30S`），用 `RAG_SOLUTION_PROPOSAL_RECOVERY_BATCH_SIZE` 设置每批数量（1–500）。关闭后台扫描后，查询原请求仍可恢复到期状态。

扫描只更新数据库状态，不访问模型、检索、文档或候选正文；数据库使用 `FOR UPDATE SKIP LOCKED` 避开其他实例正在处理的记录。有效租约、成功结果和失败结果不受影响。单次异常写固定警告“候选生成超时扫描失败，等待下一周期”，下一周期继续处理；警告不包含供应商或数据库原始异常详情。

会话结束或换浏览器不能自动恢复请求键；首版没有跨设备候选历史列表。真实审批模型、真实脱敏资料、费用和并发容量仍需独立联调。本地假网关及浏览器接口桩验证不代表生产准入。
