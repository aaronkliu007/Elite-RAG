# 钉钉组织通讯录接入

当前功能默认关闭。钉钉通讯录必须由经授权的企业内部应用提供；真实接口、权限范围和同步结果仍需在公司租户中联调确认。

## 配置

将应用 Client ID 和 Client Secret 保存在项目目录外，通过运行环境注入 `RAG_DINGTALK_CLIENT_ID` 和 `RAG_DINGTALK_CLIENT_SECRET`。设置 `RAG_DINGTALK_ENABLED=true` 后重启核心服务；不要将密钥写入仓库、日志或聊天。Windows 环境可由部署脚本从受控文件读取环境变量。

默认 `RAG_DINGTALK_AUTHORITATIVE_SCOPE_CONFIRMED=false`，只允许管理员预览。只有确认钉钉应用的通讯录可见范围完整覆盖需要维护的全部组织和成员、评估预览影响并完成真实租户验证后，才可设置为 `true` 并重启，以允许全量对账。范围缩小、接口分页缺失或结果异常时不可执行全量对账。

## 行为

系统管理员在“用户管理”中预览通讯录及触发同步；同步前重新读取上游，预览人数可能随上游变化。全量同步只管理以 `dingtalk:` 为来源的账号、部门及其成员关系，不停用本地账号或清除本地账号成员关系。钉钉来源成员失效时撤销其本系统会话。现有本地账号不会按姓名、手机号自动合并为钉钉账号；已有权限不会自动转移。

多部门用户会合并；部门、成员资料不完整或分页失败时不提交快照。钉钉返回的激活状态与企业账号停用状态不同，不能把未激活直接当成离职。

## 尚未完成

钉钉单点登录、现有本地账号与钉钉身份的安全绑定、定时和事件增量同步、同步审计和真实租户验收尚未完成。钉钉成员不会因此自动获得本地密码或知识空间授权。验证真实连接前不得将本功能视为生产可用。
