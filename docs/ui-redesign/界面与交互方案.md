# 企业知识库 UI 与交互重设计方案

状态：设计提案与静态交互原型，尚未接入生产 API，也未替换现有系统。

## 目标与现状

员工以知识问答、检索和日常文档处理为主；管理员负责空间、成员和用户治理。当前空间创建表单和用户管理入口都依赖系统管理员能力检查，位于知识空间首页；顶部导航没有系统管理入口，导致可发现性不足。当前方案工作台将创建表单直接铺在列表前，页面层次和任务入口还可以更清晰。

## 推荐结构

桌面端采用可折叠的左侧导航、轻量顶部栏和自适应内容区。主导航分为“工作台、知识问答、知识检索、知识空间、方案工作台”，管理分区包含“用户管理、问答评测”。管理分区仅在后端确认相应权限后显示，后端鉴权始终是最终依据；权限检查失败时呈现可重试状态，不能误判为无权限。顶部保留搜索入口、当前用户及退出。

| 页面 | 主要布局 | 主要操作 |
| --- | --- | --- |
| 工作台 | 问答入口、常用操作、最近可访问空间和文档 | 输入问题或进入知识空间 |
| 知识空间 | 标题与操作栏、搜索和空间卡片或列表 | 新建空间、进入空间 |
| 空间详情 | 文档列表、上传及成员管理 | 上传文档、管理成员、查看解析状态 |
| 用户管理 | 工具栏、用户列表、状态与操作 | 新建用户、停用、重置密码 |
| 知识问答 | 可滚动对话区、证据来源栏、底部输入区 | 提问、查看引用、反馈 |
| 方案工作台 | 方案列表与分步编辑工作区 | 新建方案、编辑、审核及导出 |

现有接口已支持本地用户创建/启停/密码重置、空间创建与成员管理；视觉原型中的搜索、筛选、记录和数量仅为演示，功能须以实际接口为准。“工作台”若需要最近访问、待办或统计，需要另行实现和授权校验，不得展示虚构数据为真实指标。

## 关键流程

1. 系统管理员进入“知识空间”，点击“新建空间”，在抽屉中填写名称、说明，创建成功后进入空间详情；失败保留输入，重复提交沿用幂等策略。
2. 系统管理员从“系统管理 → 用户管理”创建或维护本地用户。空间管理员在对应空间的“成员管理”中维护该空间角色；两种管理范围清楚区分。
3. 员工可从工作台直接输入问题；答案展示引用与拒答原因，查看来源时再次鉴权。未接入的多轮能力不在界面中暗示已提供。
4. 方案以列表进入详情，显示需求、大纲、章节、风险确认、定稿导出的阶段；生成内容默认待人工审阅。

## 视觉与组件

采用深海军蓝导航、浅色内容区、电光蓝主操作和少量蓝紫渐变，保持清晰的功能层级；使用统一间距、圆角、字号、状态色与线性图标。一个区域只保留一个主要操作，危险操作使用明确警示和确认。状态覆盖加载、空、失败、无权限、禁用、处理中与结果未知；长标题、姓名、路径和标识允许合理换行或截断并可查看完整内容。所有数据状态以实际接口返回为准。

## 响应式和可访问性

- ≥1200px：左导航常驻，内容区弹性布局；列表按字段重要性分配宽度。
- 768–1199px：导航收起为图标栏，内容优先；抽屉和详情栏按可用宽度调整。
- <768px：导航变为可关闭的抽屉，列表转为可读卡片；主要操作始终可见，表单单列，不使用嵌套纵向滚动。
- 键盘可达、焦点可见、语义化标签、状态不只依靠颜色；抽屉支持 Escape、焦点管理和返回触发按钮。长文本、320px 手机、1366px 桌面和大屏均需验证。

## 交付顺序与验证

先统一应用壳、导航和设计变量；再做知识空间与用户管理；然后处理检索/问答、方案工作台及其他页面；最后做响应式、键盘、权限、失败状态和真实 API 的端到端验证。保留现有路由和接口兼容性；不以界面隐藏替代服务端授权，不改变严格拒答规则。

静态原型文件：`prototype.html`。原型不操作数据、权限或真实接口；须经过用户视觉和业务评审后再实施。

参考：[Material 3 桌面与响应式导航](https://m3.material.io/foundations/desktop/components)、[Cloudscape 应用布局](https://cloudscape.design/components/app-layout/?tabId=usage)、[HashiCorp Helios 侧导航](https://helios.hashicorp.design/components/app-side-nav)。

## 细化原型覆盖范围

原型现已展示工作台、知识问答、知识检索、知识空间列表、示例空间详情、文档详情、上传流程、用户管理、方案列表、方案分步编辑与问答评测。可演示空间和用户创建抽屉、成员管理、来源查看、检索过滤、问答/严格拒答状态以及方案阶段切换。上传、评测、创建与修改均为本地演示，不请求后端；部分演示结果仅保留在当前页面，刷新后清除。未展开的文档详情会明确提示。

问答原型展示单轮提问、引用与拒答；不能把演示交互解释为已支持多轮问答、反馈持久化或自动解决冲突。方案阶段和模拟数据用于讨论信息结构，具体动作须依照现有权限、版本和审核机制实施。
