# 企业知识库交互原型产品评审

评审对象：`prototype.html` 静态原型。评审方法为代码和桌面、手机浏览器走查，围绕工作台、问答、检索、空间/文档、用户/成员、方案及评测页面；所有记录为虚构演示，非真实业务验收。

## 已发现并在原型中修正

| 优先级 | 问题 | 原型调整 |
| --- | --- | --- |
| 高 | 手机侧栏的全局样式影响问答引用栏，可能看不到来源 | 样式限制在主导航；关闭导航时从键盘及无障碍树中移除，打开后恢复 |
| 高 | 拒答或清空后仍显示旧回答的引用 | 清除引用栏；非示例问题按证据不足展示模拟拒答 |
| 高 | 空表单可显示成功；模拟创建后列表无变化 | 增加必填、重复名称及密码长度校验；创建结果在页面会话中可见并提示刷新后消失 |
| 高 | 切换方案阶段覆盖用户已输入内容 | 按当前演示方案和阶段保留页面内草稿，不写入后端 |
| 高 | 多个空间、文档入口跳到同一份不相干内容 | 示例空间按名称展示各自资料与角色；未细化的文档明确提示，不冒充其他文档 |
| 高 | 只读空间可见管理或上传操作；上传可选只读空间 | 按示例角色显示操作，上传目标只包含具有编辑能力的示例空间；真实权限仍由后端决定 |
| 中 | 用户和成员、空间与方案创建流程没有连续体验 | 示例用户可添加为空间成员；新空间可作为演示上传及方案目标；新增方案可进入对应草稿 |
| 中 | 检索或列表筛选没有结果时缺少状态；部分筛选按钮无效果 | 补充空状态，检索类型和列表阶段筛选按示例数据工作 |
| 中 | 上传按钮既无选择结果也无处理状态 | 改为选择虚构示例文件，未选择时提示；提交后在示例空间显示“解析中”，不读取或上传真实文件 |
| 中 | 用户区存在下拉视觉暗示却无操作；弹窗关闭和键盘焦点不完整 | 补充演示账号菜单、Escape、弹窗焦点限制与关闭后焦点恢复 |
| 中 | 长文本与窄屏表格可能挤压操作 | 增加长文本换行约束、桌面列宽和手机卡片布局，保留清晰主按钮 |

## 当前仍有的边界与待实施项

- 静态原型不连接真实账号、权限、文档、模型或数据库；上传、生成、评测、导出、密码重置等仍是演示，不代表后端相应功能或产品验收完成。
- 目前仅有少数文档和结果的来源详情示例，其他文档会提示尚未展开。模拟解析状态不会自动流转，问答也不会调用模型。
- 某些按钮仅用于展示未来流程，例如方案生成、提交确认、风险签认、导出、评测及账号操作；需在正式实现时分别定义加载、成功、失败、权限撤销、并发冲突和恢复流程。
- 管理菜单在原型固定为管理员视角，未模拟所有角色及权限变化；实际界面必须以后端逐动作授权为准。
- 尚未完成真实用户可用性测试、读屏器测试、多浏览器兼容或真实 API 的端到端联调；本次走查不能保证所有边缘情况或全部用户任务均无问题。
- 导航仍是单页原型内切换，不代表正式产品的深链、浏览器前进后退、刷新恢复及多用户并发行为；实施时需要完整设计和验证。

## 实施验收重点

优先在真实 UI 中接通知识空间/用户管理、权限与任务反馈，再接通检索问答、文档上传与方案工作台；统一检查 1920、1366、平板和手机，覆盖长标题、无权限、空结果、加载失败、重复提交和网络中断。实测业务资料前保留现有安全边界及严格拒答策略。

## 页面走查清单

| 页面 / 模块 | 原型中已检查 | 仍需在真实实现中验证 |
| --- | --- | --- |
| 工作台 | 导航、问答输入转交、快捷入口、空间卡片 | 最近访问、空状态、数据与授权实时性 |
| 知识问答 | 单轮输入、演示拒答、引用展示及清除旧引用 | 真实模型、引用与撤权、延迟、失败、评测及反馈持久化 |
| 知识检索 | 关键词、六类文件类型、空结果、示例来源对应 | 真实排序、分页、权限过滤、文件解析定位 |
| 知识空间及成员 | 新建、必填、重名、筛选、空间角色和模拟成员添加 | 角色变更、撤权、并发和审计、真实成员搜索 |
| 文档与上传 | 选择模拟文件、无文件提示、解析状态、只读限制 | 文件选择/传输、失败重试、解析、审核发布与真实预览 |
| 用户管理 | 创建、重复用户名、密码长度、查询空结果 | 启停、密码重置、管理员保护及真实权限审计 |
| 方案工作台 | 新建方案、所属空间、阶段切换和页面内草稿隔离 | 实际生成、引用核验、双人确认、签认、定稿及 Word 导出 |
| 问答评测 | 入口与无记录状态 | 数据集选择、执行状态、逐题复核和真实权限 |
| 全局导航 | 桌面、手机抽屉、角色入口分组、焦点恢复 | 实际鉴权后菜单、深链、浏览器历史和未保存变更处理 |

本次浏览器实际操作覆盖新建空间、无结果筛选、只读空间、用户创建及添加成员、模拟上传、来源查看、严格拒答、方案新建与阶段切换。1366 和手机宽度下用长中文名、长连续网址做溢出检查；仍需补充其他尺寸、真实用户和真实后端联调。
